# MaiHaat

**Website Name:** MàiHaat (माईहाट)

**Hindi Meaning:** बेचने वाला बाजार

**English Meaning:** Selling Market

**Logo:** 卖 (Mài)

---

## Description

**MaiHaat** is an e-commerce platform representing a "Selling Market".  
- The name combines the idea of "Mai" (Mài / माई) which symbolizes selling or ownership, with "Haat" meaning market.  
- The logo "卖" (Mài) is the Chinese character for "sell", emphasizing the marketplace concept.
